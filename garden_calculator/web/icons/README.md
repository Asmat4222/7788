# App icons

Place your PWA icons here to match `manifest.json`:

- `Icon-192.png` — 192×192
- `Icon-512.png` — 512×512

These are original brand assets you generate for GrowVault. They are
intentionally not committed as binaries; drop your own in before deploying.
Running `flutter create . --platforms web` in this directory will also
scaffold default icons and a `favicon.png` you can then replace.
